# EIL-DC-tracker

This repository contains an automated data pipeline connecting an Airtable database to a website. An R script (`airtable_pipeline.r`) pulls case data from Airtable via its API — including linked documents — filters it to published records only, and writes the result to `cases_data.json`. A GitHub Actions workflow (`.github/workflows/update-cases-data.yml`) runs that script automatically on a daily schedule, or on demand, and commits the refreshed JSON file back to the repo whenever the data changes. The HTML itself (`data-center-litigation-tracker-final.html`) reads `cases_data.json` directly and renders it as a dashboard, interactive map, filterable case list, and individual case detail pages — no server required, since everything runs in the browser. A `.gitignore` file keeps local secrets (like the Airtable API token) out of version control. Together, these pieces mean the live site stays in sync with Airtable automatically, without anyone needing to manually export data or redeploy the site by hand. The version history with all previous data updates is available within the repo in case of system failures.
